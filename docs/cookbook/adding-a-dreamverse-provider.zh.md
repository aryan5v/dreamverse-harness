# 添加或更新 DreamVerse 生成提供商

[English](adding-a-dreamverse-provider.md) | 中文

本指南说明如何将图像、音频或视频 API 接入 DreamVerse Harness，或更新现有集成。

## 1. 选择集成位置

找到负责该提供商的插件。如果现有插件已支持模型的工作流，请在主机 profile 中配置提供商的模型 ID 和本地别名。如果提供商新增了工作流，请扩展现有插件及其测试。接入新提供商时，在 `packages/dv/<provider>` 下创建 Cordis 插件，并在 DreamVerse 套件中挂载。[包设置](adding-a-package.zh.md) · [DreamVerse 套件](../../packages/bundle/dv/cordis.patch.yml)

## 2. 实现模型适配器

1. 使用稳定的提供商 ID，把原生模型 ID 保存在经过校验的配置中。为每个已启用别名的每项任务注册一个 `ModelEntry`。随模型设置更新注册表，并在插件卸载时移除条目。[模型注册表](../../packages/dv/models/README.zh.md)
2. 实现模型参数、任务 schema、请求校验和生成过程。描述支持的输入、输出尺寸、时长和参数。文本生成视频任务可仅接收文本。云端模型声明托管类型，支持指定节点的服务声明节点选择能力。[模型条目类型](../../packages/dv/models/src/types.ts)
3. 在主机上解析凭据。使用提供商文档所述的 SDK 或 API，通过素材池读取参考输入，并通过共享的生成流程返回媒体。视频任务返回片段和尾帧。[镜头生成](../../packages/dv/shot-render/README.zh.md)
4. 返回错误并使用提供商文档规定的取消机制。如果取消只能停止本地监控，请说明远程任务和计费的后续行为。

## 3. 编写提供商维护指南

每个新增的生成提供商都必须提交 `docs/cookbook/providers/<provider>.md` 及其中文版，并从提供商 README 链接该指南。新增模型或 API 变更影响维护流程时，请同步更新。

说明模型映射与限制的修改位置、支持的 SDK 或 API 版本、凭据引用、测试复现、取消和计费行为，以及 PR 需附上的验证证据。提供商专用的命令、工作流和排障方法写在该指南中。

## 4. 验证并提交拉取请求

1. 使用测试替身覆盖注册与移除、无效输入、提供商错误、取消和媒体导入。运行提供商的定向测试和相关套件测试。[测试规范](../testing.zh.md)
2. 在 DreamVerse profile 中配置模型。确认模型出现在 `dv_models_list` 中，并通过 `dv_models_get` 核对任务和参数。协议或模型变更时，若有测试凭据并获准产生费用，请按提供商指引进行线上验证。记录模型、任务和结果。
3. Fork 仓库，向默认分支提交聚焦单项变更的拉取请求。提供相关的提供商文档链接和验证方法。提交内容和测试输出都不得包含密钥、带签名的媒体 URL 或私有部署详情。[贡献指南](../../CONTRIBUTING.zh.md)
